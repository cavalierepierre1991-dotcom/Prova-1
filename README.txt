# Sky Rush V3 — Demo Ultimate

Questa è una simulazione giocabile della V3 pensata come base visiva del gioco futuro:
- grafica 3D fantasy cinematica
- volo libero in spazio aperto
- personaggio umano fantasy
- controllo touchscreen con joystick
- movimento verticale/orizzontale
- boost/abilità
- HUD con punteggio, velocità e distanza
- mondo con isole, montagne/vegetazione e cristalli
- avvio diretto in partita

## Pubblicazione GitHub Pages
Carica `index.html` nel repository e imposta GitHub Pages sulla branch principale/root.
